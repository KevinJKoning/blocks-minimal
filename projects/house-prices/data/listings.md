The listings, as a **CSV**: one row per listing from a year of portal scrapes, repeats included.

| column | means |
|---|---|
| `listing_id` | an identifier, unique per row (a repeated advert has a new one) |
| `neighbourhood` | the neighbourhood the listing is in |
| `price` | the asking price, in the listings' currency |
| `area_m2` | the floor area in square metres; blank when the listing has none |
| `rooms` | the number of rooms |
| `listed_on` | the date listed, `YYYY-MM-DD` |
