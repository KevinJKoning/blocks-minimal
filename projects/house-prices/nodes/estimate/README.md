# How much should a neighbourhood's own listings count against the city's?

A neighbourhood with three or four listings has a noisy median. Shrinking it toward the
city-wide median steadies it, but only if the neighbourhoods really sit near the city's level,
which is what the data is meant to show. What bears on the choice: the typical error and the
worst neighbourhood on each option's page, and whether the thin neighbourhoods are the ones
that move. The plain median is the option to beat: the answer says what shrinking buys.
